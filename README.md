# Registro Associazioni - Pronto da pubblicare

## Cosa c'è dentro:
- app.py -> il form web con logo
- logo.png -> metti qui il tuo logo (sovrascrivi questo file)
- associazioni.xlsx -> verrà creato automaticamente
- requirements.txt -> librerie necessarie

## Come mettere GRATIS online in 2 minuti:

1. Vai su github.com -> New repository -> nome: registro-associazioni -> Create
2. Carica TUTTI i file di questa cartella (drag & drop)
3. Vai su share.streamlit.io
4. Clicca "Create app" -> seleziona il tuo repo -> Deploy!
5. Avrai un link tipo: https://registro-associazioni.streamlit.app

Puoi mandare quel link a chi vuoi, compila dal telefono e tu scarichi l'Excel!

## Logo:
Sostituisci logo.png con il tuo logo. Deve chiamarsi esattamente logo.png
