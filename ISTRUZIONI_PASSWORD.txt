PASSWORD APP ANA VARESE
Default: ANA2025

COME CAMBIARE PASSWORD:
1. Apri app.py con Blocco Note
2. Cerca riga: APP_PASSWORD = "ANA2025"
3. Cambia ANA2025 con tua password
4. Salva e carica su GitHub

PASSWORD SICURA CON SECRETS (consigliato):
Su Streamlit Cloud:
- Manage app -> Settings -> Secrets
- Inserisci:
APP_PASSWORD = "tua_password_super_segreta"

Il codice usera automaticamente secrets se presente.
